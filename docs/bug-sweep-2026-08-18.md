# Bug sweep — 2026-08-18

**Status: all confirmed findings resolved the same day.** A fix wave of five Opus and
five Antigravity agents (disjoint file ownership) closed every confirmed finding; two
(the OCR beam-search ordering and the jaconv voiced-mark mappings) were instead
disproven during fixing with evidence from the bundled Python packages and pinned by
regression tests as correct-as-is. Suites after the wave: 918 vitest / 145 cargo, all
green, plus the five golden families re-verified against the real models.

Eighteen read-only finder agents swept the codebase area by area; every report was then
adversarially re-verified by an independent agent instructed to refute each finding.
Roughly 66 findings survived verification (verdict CONFIRMED); the refuted ones are
dropped here. The complete raw material — every finder report (`findings*-*.md`) and
every per-finding verdict with its refutation reasoning (`verdicts*-*.md`) — is
preserved verbatim in `docs/bug-sweep-2026-08-18/`; this file keeps the ranked
substance. One gap: the round-2 `rust-crops-analyze` and `rust-textdetector` finder
runs died to a tool permission block and were re-run read-only as round 3 — only the
round-3 versions exist.

## Critical — data loss

1. **Chapter-switch save race can overwrite the wrong chapter's file.**
   `openChapter` replaces `app.pages` while `app.chapterRef` still points at the old
   chapter; a debounced autosave, a `flushSave`, or the error path through `goBack()`
   during the awaited `setResidentWindow` writes chapter B's pages into chapter A's
   `chapter.json`. Three verified variants, plus a fourth: no sequence token across the
   decode awaits, so a slow open can finish after a faster later one and clobber state.
   (`library.svelte.js:1049-1160`)
2. **Undo journal races.** `openHistory` is fired un-awaited by `openChapter` — an edit
   made before it resolves is overwritten; `closeHistory`'s guard compares `dir` against
   itself on a close-then-reopen of the same chapter and wipes the live stack, disabling
   history saves for the session; undo/redo updates memory and `chapter.json` but never
   schedules `history.json`, so a crash >800 ms later diverges replay.
   (`history-file.svelte.js:180,281-287`, `history.svelte.js:315`)
3. **Detect wipes translate-mode work.** `applyDetection` rebuilds `p.lines` with
   `en: ''` and drops free-typed lines (`n < 0`) — re-running Detect after translating
   a page erases every translation on it. It also clears `p.boxes` without deselecting,
   leaving `selectedId`/`editingId` pointing at dead boxes. (`store.svelte.js:1337`)
4. **`deleteChapter` leaves a dangling `coverChapterId`** in `project.json`, permanently
   suppressing cover updates. (`library.svelte.js:376-382`)
5. **`replaceCleanedPages`/`setPageCleaned` never re-measure**, so `chapter.json` keeps
   the raw dimensions and PSD exports mismatch when cleaned art differs in size.
   (`library.svelte.js:879,921`)

## High — crash / brick

6. **Rust engine mutex poisoning bricks Detect.** A panic inside `analyze_blocking`
   poisons the sessions mutex and every later command's `if let Ok` silently no-ops until
   app restart. Also verified: concurrent cold-start downloads race the same `.part`
   path; `cache_clear` drops the lock before deleting so a concurrent analyze reloads
   mid-delete; the download does hundreds of MB of sync file I/O on the async runtime;
   a failed rename leaks the `.part`. (`engine.rs:129,175-215,305-384`)
7. **Importer crashes on legal JSON.** `normalizeTranslations(null)`, `{pages:{}}`,
   `[null]`, and `{texts:[null]}` all throw; `n: 0` lines renumber into duplicate
   `n: 1`, shadowing lines in `lineByN`. (`importer.js:27-64,36`)
8. **PSD export crash on an empty raster-only box** — `renderBoxLayer` returns null and
   ag-psd dies serializing a layer with no channels. (`psd.js:336-364`)
9. **`measure.js` NaN propagation** when `letterSpacing` is undefined or `size` is 0:
   `wrapLines` stops breaking lines, `arcLayout` emits NaN coordinates.
   (`measure.js:55-58,82,111`)
10. **Letterbox collapses to a 0-width tensor** on extreme aspect ratios (a 1×2000
    strip-shaped image at 640 input) — division by zero on the inverse map. Directly
    relevant to longstrip chapters. Clamp `inner_w/h` to ≥ 1. (`geometry.rs:63-80`)

## Medium — wrong output

11. **OCR beam search diverges from transformers**: the no-repeat-trigram ban is applied
    after `log_softmax` instead of before, deflating surviving candidates by the banned
    mass. The three golden pages pass, but other inputs can flip tokens. Also two
    missing half-width voiced-kana mappings in the `h2z` port. (`ocr.rs:569-573,242-264`)
12. **`examine_textblk` NaN distances** via unclamped `.acos()` on collinear vectors —
    poisons reading order downstream. (`textblock.rs:281-282`)
13. **Longstrip races**: `pageIndexAtCenter` jumps to chapter end while pages are
    unmeasured; scroll-sync effect and the height-radius effect read page dims inside
    `untrack` so they never re-run when decodes land; `focusPage` fights the scroll
    listener and clears selection; `addEmptyBox` on an unmeasured page lands at (0,0).
    (`strip.js:55`, `EditorRoot.svelte:106`, `RefSidebar.svelte:41`, `Canvas.svelte:448`)
14. **Translate mode**: ⌘Z replays typeset history (place actions) inside translate
    mode past the gates; queue tag form state leaks across page switches; text-JSON
    writes `width: 0` for unmeasured pages (`?? PAGE_W` never fires — 0 is not nullish).
15. **applyBulk in longstrip only touches the current page's boxes** though targets can
    be selected across visible pages. (`store.svelte.js:2044`)
16. **PSD/export edges**: foreign PSD import uses glyph ink bounds instead of
    `boxBounds` (boxes shrink); export-name stem corruption via the `-\d+$` strip;
    text-json materializes `tags` arrays, defeating `carryTagsForward` on re-import.
17. **Fonts**: UTF-16BE odd-length PS names decode with U+FFFD (Photoshop mismatch);
    `restoreFonts` can overwrite a face added mid-restore. (`fonts.js:165,554`)
18. **page-images**: no epoch check in `withPageImages` across chapter switches; late
    `onload` after eviction misfiles dims; `hasRawImage` checks `dirs` not `dirs.raws`;
    `psdSelfTest` reads images without pinning.
19. **TextBox/layout**: rotation handle clamps at 180° making -180..-90 unreachable;
    curved-text uppercase styles measure lowercase glyphs (UI/export divergence);
    balloon `fitRect` rebuilds from outer rows instead of inliers.
