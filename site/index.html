lettering for scanlation, without Photoshop

Download for macOS (Apple Silicon) Download for Windows Download for Linux (x86_64) Download for Linux (ARM64)

v0.3.0 · free · MIT

linux needs glibc 2.39+ and webkit2gtk 4.1 · x86_64 uses gpu when available · arm64 is cpu-only

how it is meant to be used: translators translate and tag every bubble in translate mode, then typesetters set a font per tag, place the boxes and tune them. auto placement can be turned off.

  • text box detection and auto placement
  • tags, so you stop scrolling the font list for every line
  • auto fit to balloon, flaky, so it can be switched off
  • autosave, undo that survives a relaunch
  • bulk restyle by tag or selection across a chapter
  • effects: warp, stacked strokes and shadows, curve, arc, wave, blur, motion blur, roughen, mask clipping
  • fills: solid, pattern and gradient
  • export PNG, JPG, WebP or JSON
  • paged manga and longstrip webtoons
  • auto updates
  • under a gigabyte of memory over hundreds of pages

psd export is unfinished, do not rely on it yet
